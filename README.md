# Linux et terminal : parcours d'apprentissage

Je me prépare au **Pré-MSc Epitech** (rentrée septembre 2027) après une formation front-end (React, voir mon dépôt `react-exercices`). Ce dépôt rassemble mes notes et mes exercices sur Linux, le terminal et les bases de l'informatique.

- Windows + WSL (Ubuntu)
- Git en SSH, commandes git lancées depuis PowerShell
